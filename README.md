# 생명 시스템의 구성

2022 개정 교육과정 고등학교 생명과학의 **생명 시스템의 구성**을 학습하는 정적 웹페이지입니다.

- 웹페이지: https://biteachu.github.io/life-systems-2022/
- 저장소: https://github.com/biteachu/life-systems-2022
- 실행: `index.html`을 브라우저로 열면 됩니다. 별도 서버·설치·인터넷 연결이 필요하지 않습니다. 출처 링크는 인터넷 연결이 필요합니다.

## 학습 구성

성취기준에 대응하는 핵심 설명 7개, 생명 시스템과 생태계 도식, 4지선다 연습문제 3개, 펼쳐 보는 정답과 해설을 제공합니다. 답은 자동 채점하거나 저장하지 않습니다.

| 코드 | 내용 | 문항 연결 |
|---|---|---|
| [12생과01-01] | 생물과 생명과학의 특성 | 설명 |
| [12생과01-02] | 세포부터 생태계까지 구성 단계 | 1 |
| [12생과01-03] | 물질대사와 에너지 전환 | 2 |
| [12생과01-04] | 기관계의 통합적 작용 | 2 |
| [12생과01-05] | 물질대사 관련 질병 조사와 생활 습관 | 설명 |
| [12생과01-06] | 생태계의 물질 순환과 에너지 흐름 | 3 |
| [12생과01-07] | 개체군·군집과 상호작용 | 1 |

연습문제는 대표 개념 확인용입니다. 조사·발표·협력적 소통 수행을 평가하거나 단원 전체의 성취를 보장하지 않습니다. 설명·도식·문제는 별도로 작성한 자료이며 공식 교과서나 교육부 문항이 아닙니다.

## 근거와 검증

- [교육과정 MCP](https://github.com/raphysicst-create/korean-secondary-learning-map-mcp) v0.3.0의 `get_standard`로 7개 성취기준을 실제 조회했습니다.
- 원응답, 조회 일시, 원문, 출처 식별자 및 검증 기록은 `curriculum-evidence.json`에 있습니다. 웹페이지는 이 응답을 제작 시 반영한 정적 문서로, 방문자에게 MCP 실행을 요구하지 않습니다.
- [교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&search=)의 별책9 과학과 교육과정 HWP를 공식 첨부 ZIP에서 확보하여 kordoc 4.24.12로 원문을 추출했습니다. OCR은 사용하지 않았고 파싱 경고는 없었습니다.
- MCP가 반환한 7개 `officialText` 모두 교육부 HWP에서 공백을 제외하고 일치함을 확인했습니다. 원응답의 출처 메타데이터는 수정하지 않았으며, 해당 메타데이터의 2024 고시 식별자·PDF 페이지를 독립 검증한 것으로 주장하지 않습니다.
- 원문 내 줄바꿈 때문에 갈라진 단어는 화면에 표시할 때만 정상화합니다. 나머지 원문은 그대로 보존합니다.

## 디자인

[트리플 소개 페이지](https://triple.guide/intro)의 공개 CSS를 참고했습니다. 시스템 산세리프, 굵은 제목, 흰 배경, 선명한 파란색, 16~20px 카드 모서리, 부드러운 그림자를 학습 페이지에 맞게 적용했습니다. 원본 사이트의 로고·사진·코드는 복제하지 않았습니다.

- 주요색 `#368FFF`, 작은 글씨와 버튼 `#1769D2`, 본문 `#3A3A3A`
- 반응형 단일 페이지, 키보드 포커스, 터치 입력, 움직임 줄이기 설정 지원
- 그림은 자체 제작한 인라인 SVG와 HTML/CSS 구성도
- 실행 시 외부 폰트·스크립트·이미지 의존성 없음

## 파일

- `index.html`: 모든 화면, 스타일, 도식, 정답
- `curriculum-evidence.json`: MCP 원응답과 교육부 원본 대조 기록
- `tools/check_page.py`: 독립된 헤드리스 브라우저에서 실행하는 기능·반응형 검사
- `.nojekyll`: GitHub Pages의 정적 파일 게시 설정
- `review/`, `.tools/`: 로컬 검증·개발 자료로 공개 저장소에서 제외

## 검사 결과와 재실행

Microsoft Edge의 독립된 헤드리스 세션으로 1440px·768px·390px 너비에서 검사했습니다.

- 가로 넘침 없음, 문항별 단일 선택, 정답 열기·닫기 정상
- 키보드 Enter로 정답 펼치기, 포커스 표시, 내부 이동 링크 정상
- 호버 배경 변화 및 `prefers-reduced-motion`에서 이동 제거 확인
- 성취기준 원문 7개 일치, 문항 3개·보기 각 4개, 중복 ID·잘못된 내부 링크 없음
- 외부 런타임 의존성 및 브라우저 페이지 오류 없음
- PC·모바일 전체 화면 캡처로 여백, 도식, 카드 배치 확인

Python에 `playwright`를 설치하고 Microsoft Edge가 있는 환경에서 다음을 실행합니다.

```sh
python tools/check_page.py
```

검사 결과와 화면 캡처는 `review/`에 저장됩니다. 검사 도구는 웹페이지 실행에는 필요하지 않습니다.

## 배포

공개 저장소의 `main` 브랜치 루트를 GitHub Pages 게시 원본으로 사용합니다. `main`에 수정 사항을 푸시하면 Pages에서 다시 빌드합니다.

기술적·내용적 검사를 수행했지만 향후 교육과정 변경이나 자료 개정은 자동 반영되지 않습니다. 변경 시 MCP 재조회 및 공식 원문 대조가 필요합니다.
